# FE01-08 — Instalando Visual Studio Code e Extensões

## Sobre o Visual Studio Code (VS Code)

O **Visual Studio Code** é o editor de código-fonte gratuito mais utilizado na indústria de desenvolvimento de software, desenvolvido pela Microsoft e disponível para Windows, macOS e Linux.

---

## Principais Recursos Nativos

- **Terminal Integrado:** permite executar comandos do sistema operacional diretamente de dentro do editor (`Ctrl + \``).
- **Emmet Integrado:** recurso nativo de autocompletar snippets rápidos de HTML/CSS.
  - Digitar `!` em um arquivo `.html` e pressionar `Tab` ou `Enter` gera a estrutura HTML5 completa automaticamente.
  - Digitar `ul>li*3` cria uma lista com três itens instantaneamente.
- **Gerenciador de Arquivos e Pastas:** visualização clara da árvore do projeto.

---

## Extensões Recomendadas para HTML e CSS

Para instalar, abra o menu lateral de extensões no VS Code (`Ctrl + Shift + X`) e pesquise por:

1. **Live Server** (por *Ritwick Dey*):
   - Inicia um servidor de desenvolvimento local.
   - Recarrega a página no navegador automaticamente a cada salvamento de arquivo (*Live Reload*).
2. **Auto Rename Tag**:
   - Ao alterar o nome de uma tag de abertura, a tag de fechamento correspondente é renomeada de forma automática.
3. **Prettier - Code Formatter**:
   - Padroniza a indentação e o formato do código ao salvar (`Format on Save`).
4. **Color Highlight**:
   - Exibe a cor real diretamente atrás do código hexadecimal ou RGB no arquivo CSS.
