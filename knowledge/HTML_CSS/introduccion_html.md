# Aula - Introdução ao HTML

## Introdução

O HTML, sigla para HyperText Markup Language, é uma linguagem de marcação utilizada para descrever a estrutura e o significado dos elementos presentes em uma página web. Ele permite que os desenvolvedores criem elementos como títulos, parágrafos, imagens, links e muitos otros, que compõem o conteúdo de uma página.

## Elementos

Os elementos HTML (ou tags) são blocos de construção fundamentais para a criação de páginas web. Eles são representados por tags, delimitadas por `"< >"` (menor que e maior que) e fornecem a estrutura e o significado para o conteúdo exibido no navegador.

Os elementos HTML podem abranger uma ampla variedade de tipos de conteúdo, como texto, imagens, vídeos, links e muito mais. Eles permitem que você organize e apresente informações de forma lógica e estruturada.

Para entender melhor, vamos dar uma olhada em um exemplo simples de um elemento HTML:

```html
<p>Este é um parágrafo.</p>
```

Nesse exemplo, usamos a tag `<p>` para criar um parágrafo de texto. A tag de abertura `<p>` indica o início do parágrafo, e a tag de fechamento `</p>` indica o fim do parágrafo. Todo o conteúdo que estiver entre essas tags será considerado parte desse parágrafo.

## Outras tags

Ao desenvolver páginas da web, é essencial entender as principais tags HTML, pois elas são os blocos de construção fundamentais do conteúdo na web. As tags HTML são elementos usados para marcar e estruturar diferentes partes de uma página. Cada tag tem um propósito específico e determina como o conteúdo será apresentado e interpretado pelo navegador. Aqui vão algumas:

1. `<h1>` - `<h6>` : Essas tags são usadas para definir os títulos e subtítulos em uma página. `<h1>` é o título principal e `<h6>` é o menor subtítulo.
2. `<p>` : Essa tag é usada para criar parágrafos de texto em uma página. É ideal para agrupar texto em blocos coesos.
3. `<a>` : Essa tag é usada para criar links em uma página. É usada em torno do texto ou imagem que será clicado para direcionar o usuário para outra página ou recurso.
4. `<img>` : Essa tag é usada para exibir uma imagem em uma página.

## Conclusão

À medida que você avança em sua jornada na programação, irá explorar uma ampla gama de elementos HTML e aprender como usá-los para criar páginas da web interativas e envolventes.
