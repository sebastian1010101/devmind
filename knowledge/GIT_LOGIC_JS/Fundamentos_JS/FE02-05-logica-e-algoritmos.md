# FE02-05 — Lógica e Algoritmos

## O que é Lógica de Programação?

**Lógica de Programação** é a habilidade de estruturar pensamentos e raciocínios de forma ordenada para resolver problemas ou atingir objetivos bem definidos por meio de um computador.

Computadores são máquinas extremamente rápidas, porém desprovidas de intuição: eles executam rigorosamente apenas as instruções fornecidas pelo programador, na ordem exata em que foram escritas.

---

## O que é um Algoritmo?

Um **algoritmo** é uma sequência finita, ordenada e não ambígua de instruções ou passos necessários para realizar uma tarefa ou solucionar um problema.

### Exemplo do Cotidiano: Fazer um Café

1. Verificar se há água na chaleira.
2. Se não houver água, encher a chaleira até o nível indicado.
3. Colocar a chaleira no fogo até ferver.
4. Colocar o filtro de papel no suporte.
5. Adicionar o pó de café na medida adequada.
6. Despejar a água quente sobre o pó em movimentos circulares.
7. Aguardar a filtragem completa e servir na xícara.

---

## As Três Fases de um Algoritmo Computacional

Todo algoritmo em software opera sobre três etapas fundamentais:

```text
+-----------------------+     +-----------------------+     +-----------------------+
|        ENTRADA        | --> |     PROCESSAMENTO     | --> |         SAÍDA         |
|  (Dados fornecidos    |     |  (Cálculos, regras,   |     |  (Resultados gerados, |
|   pelo usuário/banco) |     |   decisões e lógica)  |     |   exibição na tela)   |
+-----------------------+     +-----------------------+     +-----------------------+
```

1. **Entrada (Input):** dados que o programa recebe (ex: usuário digita dois números).
2. **Processamento:** operações que o computador realiza sobre esses dados (ex: somar os dois números).
3. **Saída (Output):** resultado entregue ao usuário (ex: exibir o total da soma na tela).

---

## Características de um Bom Algoritmo

- **Finitude:** deve ter um início e um fim claros; não pode entrar em execução perpétua involuntária.
- **Precisão / Clareza:** cada instrução deve ser inequívoca, sem margem para duplas interpretações.
- **Efetividade:** todas as etapas descritas devem ser executáveis na prática.
